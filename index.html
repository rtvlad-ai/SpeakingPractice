Gemini API

Без ключа работает локальный собеседник: он разбирает твой ответ, реагирует на него и ведёт свою линию вопросов. Проверка грамматики работает всегда, в том числе без ключа. С ключом диалог становится полностью свободным. Ключ в localStorage — только для личного теста; для публичной страницы нужен backend-прокси.

Микрофон

Микрофон, ключ и данные

  • Микрофон включается только после нажатия кнопки и выключается сам после фразы.
  • Распознавание речи делает браузер; качество зависит от устройства.
  • Текст уходит в Gemini только если ты сам ввёл ключ.
  • Проверка грамматики выполняется локально в браузере.
  • Для публичного запуска нужен backend endpoint, который хранит ключ на сервере.
  • Трекеров и аналитики на странице нет.
