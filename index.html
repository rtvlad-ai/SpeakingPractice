Профиль

Статус растёт сам: приложение считает, какие фразы ты уже держишь, и подкидывает слабые места в разговоре и тесте. Уровни, проценты и грамматические термины наружу не выносятся.

Оформление

Фото берутся с Unsplash по сети. Хочешь офлайн или свои картинки — положи рядом с index.html папку photos с файлами greeting.jpg, school.jpg, hobbies.jpg, cafe.jpg, shopping.jpg, routine.jpg, travel.jpg, family.jpg: они используются первыми. Если фото недоступно, остаётся цветной фон темы.

DeepSeek API

Без ключа работает локальный собеседник: он разбирает ответ, реагирует на него и ведёт свою линию вопросов. Произношение, фразы и очки считаются локально и без ключа. С ключом DeepSeek (api.deepseek.com, модель deepseek-chat) разговор становится свободным. Ключ в localStorage — только для личного теста; для публичной страницы нужен backend-прокси.

Голос собеседника

Микрофон

Микрофон, ключ и данные

  • Микрофон включается только после нажатия кнопки и выключается сам после фразы.
  • Распознавание речи делает браузер; качество зависит от устройства.
  • Текст уходит в DeepSeek только если ты сам ввёл ключ.
  • Проверка грамматики и оценка произношения выполняются локально в браузере.
  • Для публичного запуска нужен backend endpoint, который хранит ключ на сервере.
  • Трекеров и аналитики на странице нет.
