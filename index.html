Настройки

Без ключа работает демо-режим: голос, темы, подсказки, озвучка и проверка частых ошибок. «Запомнить» кладёт ключ в localStorage — только для личного теста на своём устройстве. В опубликованной странице ключ виден любому посетителю: там нужен backend-прокси.

Микрофон

Микрофон, ключ и данные

  • Микрофон включается только после нажатия кнопки и выключается сам после фразы.
  • Распознавание речи делает браузер; качество зависит от устройства.
  • Текст уходит в Gemini только если ты сам ввёл ключ.
  • API-ключ нельзя оставлять в опубликованном frontend-коде.
  • Для реального публичного запуска нужен backend endpoint, который хранит ключ на сервере.
  • Трекеров и аналитики на странице нет.
